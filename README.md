NeOOsin

Công cụ tra cứu thông tin OSINT mạnh mẽ (IP, tên miền, DNS, email, số điện thoại, toạ độ ảnh, mạng xã hội).

Cài đặt

Cài đặt trực tiếp từ GitHub:

```bash
pip install git+https://github.com/Minhbach16-cmyk/neosi-.git
```

Hoặc cài đặt từ mã nguồn đã tải về máy:

```bash
pip install .
```

Sử dụng

Sau khi cài đặt thành công, khởi chạy tool bằng lệnh:

```bash
neoosin-vi
```

Tính năng

· Tra cứu thông tin IP / Tên miền (WHOIS, DNS, SSL, HTTP).
· Tra cứu số điện thoại.
· Kiểm tra email (định dạng, MX, rò rỉ dữ liệu, header).
· Trích xuất toạ độ GPS từ ảnh (EXIF).
· Tìm kiếm tài khoản mạng xã hội.
